* Custom actions can be implemented in 3 ways
    * composite 
        * yaml steps bundled together 
        * no coding is needed , u can use existing actions 
        * most commonly used by devops/cloud engineers
    * javascript
        * js code written based on your needs, run directly on the runner
        * too complex logic, github api call 
        * u need to know java script 
    * docker 
        * runs inside a container 
        * slower
        * not so recommended 
### Composite Action Structure
* A composite actions lives in a folder within `action.yml` file
```
.github/
    workflows
        first-pipeline.yaml
        ci.yaml
        ci-full-promotion.yaml
    actions/
        java-build/
            action.yml          <- Composite action
        notify-failure
            action.yaml         <- Composite action
        docker-build-push
            action.yaml         <- Composite action
```
